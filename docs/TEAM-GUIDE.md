# AgentDesk 팀 공유 — 팀원 설치·연결 가이드

AgentDesk는 내 PC에서 돌아가는 AI 코딩 에이전트 세션(Claude Code·Gemini CLI·Codex CLI)을 한눈에 보여 주는 데스크톱 위젯입니다.
**팀 공유**를 켜면 같은 사내망에 있는 팀원의 세션 목록도 "팀" 탭에서 볼 수 있습니다. 1단계는 **읽기 전용**입니다. 팀원 세션에 입력하거나 화면을 보는 기능은 다음 단계에서 추가됩니다.

## 1. 설치 (macOS)

1. 전달받은 `AgentDesk-<버전>-arm64.dmg`(Apple Silicon) 또는 `AgentDesk-<버전>.dmg`(Intel)를 엽니다.
2. `AgentDesk.app`을 `Applications` 폴더로 끌어다 놓습니다.
3. 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜨면, **Finder에서 앱을 우클릭 → 열기**로 한 번 열어 줍니다. 사내 배포용이라 Apple 공증을 받지 않았습니다.
4. 앱이 뜨면 온보딩에서 언어를 고르고, **정확 감지(에이전트 훅)** 를 켭니다. 켜면 Claude Code 등 CLI 설정에 상태 알림 훅이 추가되어 세션 상태가 정확히 보입니다. 꺼도 Orca 세션은 보이지만 터미널에서 띄운 세션은 보이지 않습니다.

> 필요한 것: macOS 13 이상, Node.js(`/opt/homebrew/bin/node` 또는 `/usr/local/bin/node`). 훅과 팀 공유 서버가 Node로 동작합니다.

## 2. 팀 공유 켜기

1. 위젯 오른쪽 위 ⚙ → **팀 공유** → **설정 파일 만들기**를 누릅니다. `~/.agentdesk/team.json` 예시 파일이 Finder에 표시됩니다.
2. 파일을 텍스트 편집기로 열어 아래처럼 채웁니다.

```json
{
  "name": "will",
  "token": "팀이 함께 쓰는 비밀 문자열",
  "port": 7331,
  "bind": "0.0.0.0",
  "peers": [
    { "name": "neo", "host": "192.168.10.120:7331" }
  ]
}
```

| 항목 | 뜻 |
|---|---|
| `name` | 팀 탭에 표시될 내 이름 (영문 권장) |
| `token` | **팀 전원이 똑같이** 쓰는 비밀 문자열. 예시 값 `change-me-shared-secret` 그대로 두면 켜지지 않습니다 |
| `port` | 내 PC가 여는 포트. 기본 7331 |
| `bind` | `0.0.0.0`이면 사내망에서 접속 가능. 나만 볼 때는 `127.0.0.1` |
| `peers` | 보고 싶은 팀원의 이름과 `IP:포트`. 여러 명이면 항목을 추가합니다 |

3. 저장하면 30초 안에 반영됩니다. 바로 적용하려면 앱을 종료했다가 다시 엽니다.
4. macOS가 "수신 연결을 허용하시겠습니까?" 하고 물으면 **허용**합니다.
5. **팀** 탭을 열면 `@neo` 같은 팀원 이름 아래에 그 사람의 세션이 보입니다.

내 IP는 터미널에서 다음 명령으로 확인해 팀원에게 알려 줍니다.

```
ipconfig getifaddr en0
```

팀원 쪽에서도 자기 `team.json`의 `peers`에 내 IP를 넣어야 서로의 세션이 양쪽에 보입니다.

## 3. 무엇이 공유되나

팀원에게 보내는 것은 아래가 전부입니다.

- 세션 이름, 저장소·워크트리 **폴더명**, 브랜치
- 상태(실행 중·대기 중·완료·오류), 선택 대기 여부와 대기 시간
- 에이전트 종류, 현재 도구 이름, 컨텍스트 사용률, 응답 없음·반복 시도 표시
- "지금 하는 일" 한 줄 요약(켜 둔 경우)

보내지 않는 것: 프롬프트와 응답 본문, 도구 입력값(파일 경로·명령어), 전체 경로, 토큰·자격증명, 완료된 지 하루가 지난 세션. 서버는 `GET`만 받고 토큰이 없는 요청은 거절합니다. 누군가 내 세션에 입력할 수 있는 통로는 없습니다.

## 4. 연결이 안 될 때

팀 탭의 그룹 헤더에 원인이 표시됩니다.

| 표시 | 원인 | 조치 |
|---|---|---|
| `token mismatch` | 토큰이 다름 | 양쪽 `team.json`의 `token`을 같게 |
| `timeout` / `ECONNREFUSED` | 상대 앱이 꺼져 있거나 포트가 막힘 | 상대 PC에서 AgentDesk 실행 확인, 방화벽·VPN에서 7331 허용 |
| `ENOTFOUND` | 주소 오타 | `host`를 `IP:포트` 형식으로 |
| 설정 쪽 `team.json: …` | JSON 문법 오류 또는 토큰이 예시 값 | 파일 수정 후 저장 |

상대가 켜져 있는지는 토큰 없이도 확인할 수 있습니다.

```
curl http://<상대 IP>:7331/v1/ping
```

`{"name":"neo","at":…}` 가 돌아오면 네트워크는 정상이고 토큰 문제입니다.

## 5. 끄기

`~/.agentdesk/team.json`을 지우거나 이름을 바꾸면 30초 안에 서버가 닫히고 팀 탭이 비활성화됩니다.
