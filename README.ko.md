# AgentDesk

AI 코딩 에이전트를 위한 픽셀 아트 사무실. AgentDesk는 Claude Code 세션을 실시간으로 지켜보고(일반 터미널이든 [Orca](https://github.com/stablyai/orca) 안이든), 각 에이전트가 무엇을 하는지 대시보드와 책상에 앉은 캐릭터로 보여 주는 macOS 데스크톱 위젯입니다.

*이전 이름은 "Orca Widget"입니다. Orca는 선택 사항이며 지원하는 에이전트 CLI 하나만 있으면 동작합니다.*

**지원 에이전트:** Claude Code, Gemini CLI, Codex CLI — 각 CLI의 자체 훅 체계를 사용하므로 상태가 정확합니다. [Orca](https://github.com/stablyai/orca) 안의 세션은 Orca CLI를 통한 터미널 제어도 됩니다.

## 기능

- **실시간 대시보드** — 터미널·tmux·Orca에서 실행 중인 모든 Claude Code·Gemini CLI·Codex CLI 세션의 실제 상태(작업 중 / 입력 대기 / 선택 필요 / 완료 / 오류). 정확 감지를 켜면 Claude Code 훅 이벤트로, 아니면 터미널 화면을 읽어 판정하므로 Orca의 상태가 지연되어도 정확합니다.
- **픽셀 오피스** — 최근 세션이 캐릭터로 표시됩니다. 작업 중이면 사용하는 도구에 따라 배정된 스테이션(개발 / 조사 / 실행·테스트 / 문서화) 책상에서 도구 태그와 컨텍스트 게이지를 달고 일하고, 서브에이전트는 부모 옆에 나타나며, 쉬는 에이전트는 휴게실 소파에 앉습니다. 벽의 화이트보드가 현황을 요약합니다.
- **PM 팀** — 에이전트를 PM 자리에 드래그해 팀을 만들고 다른 에이전트를 팀원으로 끌어 넣습니다. PM에게 목표를 주면 팀 브리프를 쓰고 업무 분배를 제안하며, 승인하면 각 팀원이 브리프와 자기 태스크를 받습니다. 보고는 PM에게 자동으로 돌아갑니다.
- **선택 필요 알림** — 권한 승인이나 질문처럼 정말 사람이 답해야 할 때만 알림·토스트·트레이 배지·알림음이 뜹니다.
- **재알림·위임 세션 알림** — 승인 대기·응답 없음이 계속되면 설정한 간격(기본 15분, 세션당 한 시간에 최대 2번)마다 다시 알립니다. 나에게 위임된 팀원 세션은 입력 가능·승인 필요·완료·오류·응답 없음으로 바뀔 때 한 번씩 알리고, 토스트를 누르면 팀 탭의 그 카드로 이동합니다. 간격과 응답 없음 기준(기본 30분)은 ⚙ 설정 → 감지와 알림에서 바꿉니다.
- **검토 대기열(📥)** — 헤더의 📥 N 을 누르면 권한 요청·Jira 보고 대기·변경 보기·받은 메모·팀원 등록 요청·위임받은 세션의 입력 가능/승인 필요·한도 경고·응답 없음 세션을 한 목록(급한 순 → 오래된 순)으로 보고, 항목을 누르면 그 화면으로 이동합니다. 메모 [세션에 전달]·팀원 [추가]·권한 [거부]는 목록에서 바로 처리할 수 있습니다. 이미 있는 상태를 모아 보여 줄 뿐 알림을 따로 띄우지 않으며, ⚙ 설정 → 감지와 알림 → **대기열에 포함할 항목**에서 종류별로 끕니다.
- **도크 모드** — 헤더의 ▭ 버튼이나 ⌘⇧D(Windows·Linux: Ctrl+Shift+D)로 위젯을 화면 아래 가장자리 중앙에 붙는 얇은 가로 띠로 바꿉니다. 세션마다 픽셀 캐릭터 타일(캐릭터 아래 세션 이름, 발밑 상태 링·대기열 숫자 배지·서브에이전트 점), 팀원 세션(팀 공유 시, 🔑 위임받음), 📥 대기열·한도 막대가 한 줄에 있습니다. 띠에는 입력 줄이 따로 없고, 입력과 권한 답은 터미널 창과 말풍선에서 합니다(오류·전송 결과는 타일 위에 잠깐 뜨는 알림으로). 타일에 마우스를 올리면(0.2초) 팀원 위임 세션의 원격 터미널 창과 같은 모양의 터미널 창이 띠 위에 바로 열립니다. 이 창은 화면 200줄을 마스킹해서 1초마다 갱신하고, 입력 대기일 때 아래 입력 줄로 메시지를 보낼 수 있습니다. 권한 요청이 뜨면 입력 줄 자리에 [허용][거부]가 나오고(패널과 같은 0.8초 무장 지연·잘림 규칙), [중단](확인 후)·[터미널로] 버튼도 있습니다. 긴 줄은 창 너비에 맞춰 줄바꿈되고, Claude Code 프롬프트 틀의 괘선 행은 얇은 선 하나로 그립니다. 마우스가 타일이나 창 위에 있거나 입력 줄에 포커스·글자가 있으면 창이 유지되고, 그 밖에는 마우스가 떠나고 0.3초 뒤에 닫힙니다(Esc·바깥 클릭·다른 앱으로 전환해도 닫힘). 다른 타일에 올리면 그 세션으로 바뀌지만, 입력 중일 때는 바뀌지 않습니다. 위임받은 팀원 세션도 같은 자리에 원격 창이 열립니다. 타일을 누르면 그 세션의 실제 터미널로 바로 전환하고, 더블클릭은 패널의 그 카드로 갑니다. 키보드로는 타일에서 Enter가 터미널 창 열기, ⌘Enter(Ctrl+Enter)가 터미널 전환입니다. 세션이 선택을 기다리면(권한 요청, AskUserQuestion, 번호 선택지) 그 타일 위에 말풍선이 저절로 떠서 질문(6줄까지, 더 길면 [전체 보기]로 터미널 창)과 선택지 버튼을 보여 주고, 바로 고를 수 있습니다. 버튼은 0.8초 뒤에 눌리고, 가드레일이 위험하다고 판단한 프롬프트(예: rm -rf ~/)는 "No" 쪽만 누를 수 있습니다. 권한 요청은 터미널 창의 [허용][거부]와 같은 규칙입니다. 말풍선은 세션마다 하나씩 나란히 뜨고, 자리가 모자라면 오래된 것부터 빠집니다. 고르면 "보냄"을 표시하고 닫히며, 세션이 더 기다리지 않아도 닫힙니다. 작업 중인 타일은 캐릭터가 오피스의 작업 동작으로 움직이고, 현재 도구 표시($·✎·≡ 등)와 최근 1분 도구 호출 막대가 붙습니다. 입력 대기는 발밑 초록 링이 천천히 깜박이고, 승인 필요는 노란 ! 배지, 오류는 빨간 테두리입니다. 도크의 [허용]은 한 줄로 다 보이는 Bash 명령·짧은 요청에만 뜨고, 파일 편집·잘린 요청은 [패널에서 보기]로 패널에서 확인합니다. 띠를 끌어 둔 위치를 기억하고, 마우스가 떠나면 1.5초 뒤 흐려집니다. ⌘1~⌘9(Windows·Linux: Ctrl+1~9)는 왼쪽부터 n번째 내 타일(+N 묶음 제외)의 터미널로 바로 전환하며, 타일 이름 왼쪽에 그 번호가 흐리게 붙습니다. 선택 말풍선이 하나만 떠 있거나 마우스로 하나를 키운 상태면 숫자키 1~9로 그 선택지를 고를 수 있습니다. 이때도 0.8초 무장·가드레일 잠금 규칙은 그대로이고, 누를 수 없는 선택지는 알림으로 이유를 보여 줍니다(Esc는 말풍선을 닫지 않고 포커스만 타일로 돌립니다). 타일 오른쪽 위에는 현재 상태가 이어진 시간(3m, 1h 등)이 붙고, 입력 대기 10분·작업 중 30분을 넘기면 노란색으로 바뀝니다. 한도 막대에 마우스를 올리면 세션·주간 사용률과 초기화 시각을 작은 카드로 보여 줍니다. 내 세션이 작업을 마치면(작업 중 → 입력 대기·완료) 그 타일 위에 마지막 응답의 첫 줄(마스킹, 80자)을 완료 말풍선으로 8초 동안 띄우고, 누르면 터미널로 갑니다. 띠의 🔕 버튼은 방해 금지 모드로, 켜면 말풍선·알림·데스크톱 알림이 멈추고 타일 색과 ! 배지만 남으며, 끄면 기다리던 선택 말풍선이 바로 다시 뜹니다. 띠 위쪽 가장자리에는 내 세션마다 "지금 하는 일" 요약(대시보드 카드와 같은 내용, 마스킹·60자)을 "이름: 요약 · 이름: 요약" 한 줄로 보여 줍니다. 폭을 넘으면 천천히 흐르고(동작 줄이기·애니메이션 끔이면 멈추고 말줄임), 마우스를 올리면 멈춥니다. 타이머 페이지가 돌고 있으면 띠 오른쪽에 남은 비율 링과 남은 시간(mm:ss)이 나오고, 누르면 타이머 페이지로 가며, 끝나면 띠가 한 번 깜박입니다. 팀원 세션 타일이 6개를 넘으면 세션이 둘 이상인 팀원은 한 타일(@이름, 가장 급한 상태, 배지 합)로 묶이고, 마우스를 올리면 그 팀원의 세션 목록을, 누르면 팀 탭을 엽니다. 끌어 둔 띠 위치는 모니터마다 따로 기억하고, 모니터 구성이 바뀌어 저장한 모니터가 없으면 주 모니터의 기본 위치로 갑니다. "마우스가 멀어지면 숨기기"를 켜면 마우스가 띠를 떠나고 2초 뒤 띠가 화면 가장자리로 밀려 8px만 보이며(그동안 클릭은 뒤 창으로 통과), 마우스를 가져가거나 말풍선·알림이 뜨면 바로 돌아옵니다. ⚙ 설정 → 표시에서 시작 시 도크 모드, 도크 크기(작게: 이름 없는 40px 타일·낮은 띠, 보통, 크게: 64px 타일·큰 글자), 한 줄 요약 띠, 마우스가 멀어지면 숨기기, 완료 말풍선, 도크 애니메이션(시스템의 동작 줄이기 설정도 따름), 호버 시 터미널 창 열기(끄면 이름·상태·지금 하는 일만 작은 카드로), 흐림 정도를 고릅니다.
- **Jira 보드에 팀원 작업 표시** — 팀원 세션이 작업 중인 티켓의 카드·드로어에 "👤 이름 작업 중"이 붙고, 그 티켓을 배치하려 하면 한 번 더 확인합니다.
- **채팅 패널** — 캐릭터나 카드를 클릭하면 에이전트 화면을 읽고 메시지를 보낼 수 있고, 더블클릭하면 Orca 터미널로 전환됩니다.
- **유틸리티** — 뽀모도로 타이머.
- **Orca 유무와 무관하게 동작** — Orca가 있으면 Orca CLI로 세션 발견·채팅·터미널 제어를 하고, 없으면(Claude Code가 있는 어느 Mac이든) Claude Code 훅과 트랜스크립트로 세션을 발견합니다. tmux 안에서 실행 중인 세션은 채팅과 지시도 가능합니다. 두 종류의 세션이 한 목록에 함께 표시되며 따로 설정할 것은 없습니다.
- **영어·한국어 UI** — 기본은 영어, ⚙ 설정에서 전환.
- **외부로 나가는 글 마스킹** — Jira 댓글·Slack 회신도 보내기 직전에 메인 프로세스에서 비밀 패턴을 `[MASKED]`로 바꿉니다(Slack 브리지에서 한 번 더). 테스트 카드번호·이메일도 가려지며, 댓글 초안에 "비밀 패턴 N곳을 [MASKED]로 바꿨습니다"가 표시됩니다.

## 빠른 시작

요구 사항: macOS·Linux·Windows, Node.js 18 이상, 에이전트 CLI 하나 이상(Claude Code, Gemini CLI 또는 Codex CLI). [Orca](https://github.com/stablyai/orca) 1.4 이상은 선택 사항이며, 없으면 훅 전용 모드(Claude Code 훅 + 메시지 전송용 [tmux](https://github.com/tmux/tmux))로 동작합니다.

```bash
git clone https://github.com/choiminu/AgentDesk.git
cd AgentDesk
npm install
npm start
```

설치 파일은 [GitHub 릴리스](https://github.com/choiminu/AgentDesk/releases)에 첨부됩니다(macOS DMG Apple Silicon·Intel, Linux AppImage·.deb, Windows 설치 프로그램·포터블 .exe). 직접 빌드하려면 `npm run dist`(macOS), `npm run dist:linux`, `npm run dist:win`을 사용합니다.

새 버전이 나오면 ⚙ 설정의 "업데이트" 행에 표시됩니다. [받기]를 누르면 이 기기에 맞는 설치 파일(macOS Apple Silicon·Intel DMG, Linux AppImage, Windows 설치 프로그램)을 `~/Downloads`에 내려받아 엽니다. 맞는 파일이 없거나 내려받기에 실패하면 릴리스 페이지를 엽니다. 버전은 0.2.1부터 `0.2.1`, `0.2.2`처럼 patch 번호를 올립니다.

| 플랫폼 | 세션 상태(훅) | 채팅·지시·인터럽트 | 터미널 전환 | 종료 세션 다시 열기 |
|---|---|---|---|---|
| macOS | ✓ | Orca, tmux, iTerm2, Terminal.app | ✓ | iTerm2 / Terminal |
| Linux | ✓ | tmux만 | tmux 창 | gnome-terminal, konsole, kitty, alacritty, xterm… |
| Windows | ✓ | — | — | Windows Terminal / cmd | 유료 인증서로 서명되어 있지 않아 OS마다 첫 실행 때 한 번 확인을 요구합니다.

- **macOS** — 앱은 ad-hoc 서명되어 있습니다. 한 번 열어 보면 차단되는데, 그다음 **시스템 설정 → 개인정보 보호 및 보안**에서 **확인 없이 열기**를 누르면 됩니다. "손상되어 열 수 없음"이 나오면 터미널에서 `xattr -cr /Applications/AgentDesk.app` 을 실행한 뒤 다시 여세요.
- **Windows** — SmartScreen의 "Windows의 PC 보호" 창에서 **추가 정보 → 실행**을 누릅니다.
- **Linux** — `chmod +x AgentDesk-*.AppImage` 후 실행하거나 `sudo apt install ./agentdesk_*_amd64.deb` 로 설치합니다.

처음 실행하면 짧은 온보딩이 이 Mac의 환경(Claude Code, 위젯 훅, Orca CLI, 터미널 자동화 권한)을 점검하고 **정확 감지**를 버튼 하나로 켤 수 있게 안내합니다. 정확 감지는 Claude Code 훅을 등록해([동작 원리](#동작-원리) 참고) 상태를 추정이 아닌 이벤트로 받게 하며, 이후에도 ⚙ 설정에서 켜고 끌 수 있습니다. 온보딩을 다시 보려면 `ROCA_START_PAGE=onboarding` 으로 실행합니다.

## 동작 원리

위젯은 5초마다 `orca worktree ps`와 `orca terminal list`로 세션 목록을, 2초마다 `orca terminal read --screen`으로 열린 터미널 화면을 읽습니다. 상태는 다음 순서로 결정됩니다.

1. **훅 이벤트**(정확, 정확 감지가 켜진 경우)
2. **터미널 화면**(추정)
3. **Orca 에이전트 상태**(대체)

<summary>세션 출처 (Orca 세션과 일반 터미널 세션)</summary>

| 세션 종류 | 발견 경로 | 채팅·PM 팀·인터럽트 |
|---|---|---|
| **Orca 세션** | `orca worktree ps` + 터미널 목록, 훅 이벤트로 보강 | Orca 터미널 |
| **터미널 세션**(iTerm2·Terminal.app·tmux에서 실행한 Claude Code) | Claude Code 훅 이벤트(`~/.roca/events.jsonl`) + 트랜스크립트 메타(`/rename` 또는 AI 제목·마지막 메시지·컨텍스트·브랜치) | tmux 패널(`send-keys` / `capture-pane`), 또는 `claude` 프로세스로 찾은 iTerm2 / Terminal.app 탭(AppleScript). 종료된 세션은 클릭하면 `claude --resume`으로 다시 열립니다 |

두 종류는 훅 스크립트가 기록하는 `TERM_PROGRAM` 값(`Orca` / `iTerm.app` / `tmux` / `Apple_Terminal`)으로 구분되어 한 목록에 함께 나옵니다. Orca가 없으면 훅만이 세션 출처가 되며, 이때 대시보드에 배너가 표시되고 정확 감지가 꺼져 있으면 버튼으로 바로 켤 수 있습니다.

<details>
<summary>위젯에서 권한 승인 (Claude Code)</summary>

⚙ 설정 → 감지와 알림 → **위젯에서 권한 승인**을 켜면(기본 꺼짐, 정확 감지가 켜져 있어야 함) Claude Code가 도구 권한을 물을 때 해당 세션 카드에 도구 이름과 입력 요약(Bash는 명령 전체, Write는 내용 앞부분, Edit는 바뀌는 줄, 그 외는 입력 JSON 1,000자. 비밀값은 마스킹, 보이지 않는 문자·양방향 제어 문자는 `⟨U+XXXX⟩`로 표시)과 **[허용] [거부] [터미널로]** 버튼이 뜹니다. 헤더에 "승인 대기 N" 배지와 데스크톱 알림도 함께 나옵니다.

- **터미널 질문도 함께 뜹니다. 먼저 답한 쪽이 적용됩니다.** 터미널에서 답하면 위젯 패널은 사라집니다.
- 버튼을 누르기 전에는 아무것도 허용되지 않습니다. "항상 허용" 같은 저장 규칙은 없고, 제안된 규칙이 있어도 "이번만 허용"만 제공합니다. 거부할 때 적은 이유는 Claude에게 전달됩니다.
- 입력이 길어 화면에 다 보이지 않으면 [허용]이 꺼지고 [거부]·[터미널로]만 쓸 수 있습니다. 패널이 새로 뜬 직후 0.8초 동안은 버튼이 눌리지 않습니다.
- **위젯이 꺼져 있으면 기존처럼 터미널에서 묻습니다.** 대기 시간(기본 90초, 설정에서 60/90/180/300초)이 지나거나 [터미널로]를 눌러도 터미널 질문만 남습니다.
- 동작: `~/.claude/settings.json`의 `PermissionRequest`에 동기 훅 `~/.roca/perm-hook.sh`를 추가합니다(기존 로깅 훅과 공존). 훅은 위젯이 연 Unix 소켓 `~/.roca/perm/perm.sock`(디렉터리 0700)으로 요청을 보내고, 위젯이 시작할 때 만든 무작위 토큰(`~/.roca/perm/perm-token`, 0600, 종료 시 삭제)으로 인증합니다. 위젯의 응답은 같은 토큰의 HMAC 서명이 맞을 때만 Claude Code에 전달됩니다. 서버는 훅 이벤트로 본 세션의 요청만 받습니다. 끄면 이 훅만 제거됩니다.
- Claude Code 전용입니다(Gemini CLI·Codex CLI는 해당 없음). Windows에서는 제공하지 않습니다. 훅에 `curl`(7.84 이상)과 `openssl`이 필요하며, 없으면 터미널에서 묻습니다.

</details>

<details>
<summary>가드레일 — 위험 명령 확인 (Claude Code)</summary>

⚙ 설정 → **가드레일**을 켜면(기본 꺼짐, 권한 승인과 별개) Claude Code가 Bash 명령을 실행하거나 파일을 고치기(Edit·Write·MultiEdit·NotebookEdit) 직전에 위험 규칙(`~/.roca/guard.json`)과 맞춰 봅니다. 모드는 끔·경고(기본)·차단입니다.

- **경고**: 걸리면 터미널에서 한 번 더 확인을 받습니다(`--allowedTools`로 허용했거나 bypassPermissions 모드여도 묻습니다). **차단**: 차단 등급 규칙은 거부하고, 이유가 Claude에게 전달됩니다. 경고 등급 규칙은 확인을 받습니다.
- 내장 규칙은 Bash 명령 전체(256KB까지)를, 파일 도구는 **대상 경로만** 봅니다(내용은 보지 않음). 사용자 규칙은 명령의 앞 4,000자와 뒤 4,000자만 보므로, 그보다 긴 명령은 (끔 모드가 아니면) 확인을 받습니다. 2MB가 넘는 입력에서 대상 경로를 찾지 못해도 확인을 받습니다. `allowRepos`에 넣은 경로 안에서는 파일 경로 규칙만 건너뜁니다(Bash는 항상 검사).
- **범위 밖**: MCP 도구(`mcp__*`)·WebFetch·Read 등 다른 도구, 그리고 셸 변수로 바꾼 명령(`x=rm; $x -rf /`)이나 스크립트 파일에 써 두고 실행하는 방식은 잡지 못합니다. 샌드박스가 아니라 안전벨트입니다.
- **위젯이 꺼져 있거나 응답이 2초를 넘으면 아무것도 막지 않습니다**(fail-open). 훅이 응답을 받기 전에 끊긴 판정은 기록에 "시간 초과로 통과됨"으로 남습니다.
- 사용자 규칙의 정규식은 500자 이하, 한 번에 20ms 제한으로 실행합니다. 시간을 넘긴 차단 등급 규칙은 그 호출에서 확인을 받고, 서로 다른 입력에서 2번 넘기면 "느린 규칙"으로 표시만 합니다(끄는 것은 사용자). 경고 등급 규칙은 2번 넘기면 꺼집니다.
- 기록: `~/.roca/guard-log.jsonl`(0600, 최근 2,000줄, 비밀값 마스킹). 대시보드 "오늘 가드 N"과 세션 카드 "가드 N" 배지에서 볼 수 있습니다.
- 동작: `~/.claude/settings.json`의 `PreToolUse`(matcher `Bash|Edit|Write|MultiEdit|NotebookEdit`)에 동기 훅 `~/.roca/guard-hook.sh`(제한 시간 3초)를 추가하고, 권한 승인과 같은 Unix 소켓·토큰·응답 HMAC 검증을 씁니다. `jq`가 있으면 판정에 필요한 필드만 보냅니다. 팀원의 원격 입력도 같은 규칙 파일로 검사합니다(내장 규칙은 항상 적용).

</details>

<details>
<summary>훅 기반 정확 감지</summary>

정확 감지를 켜면 이 Mac에 설치된 모든 에이전트 CLI에 위젯 훅이 추가됩니다: `~/.claude/settings.json`(Claude Code), `~/.gemini/settings.json`(Gemini CLI), `~/.codex/hooks.json`(Codex CLI). 기존 훅은 보존되고 이전 파일은 `~/.roca/`에 백업됩니다. 나중에 설치한 CLI는 다음 위젯 시작 때 자동으로 포함됩니다. 훅 스크립트 `~/.roca/hook.sh`는 이벤트를 `~/.roca/events.jsonl`에 한 줄씩 덧붙이고 즉시 종료하며, 위젯이 이 파일을 감시합니다. Claude Code는 훅 설정을 즉시 다시 읽으므로 실행 중인 세션에도 적용됩니다. 끄면 위젯 항목만 제거됩니다.

| 훅 이벤트 | 위젯 상태 |
|---|---|
| `UserPromptSubmit`, `PreToolUse`(도구명·대상 기록), `PostToolUse` | 작업 중 |
| `Stop` | 대기(10분 후 완료) |
| `PermissionRequest`, `Notification`(`permission_prompt`, `agent_needs_input`, `elicitation_*`), `PreToolUse(AskUserQuestion)` | 선택 필요 |
| `SubagentStart` / `SubagentStop`, 서브에이전트 안의 `PreToolUse` | 서브에이전트 등장·도구 표시·퇴장 |
| `SessionEnd` | 완료 |

이벤트는 `cwd`와 워크트리 경로로 세션에 매칭됩니다. 훅 데이터가 없는 세션(다른 에이전트, 훅 미설치)은 화면 판독으로 동작합니다.
</details>

<details>
<summary>화면 기반 판별</summary>

마지막 `❯` 프롬프트 줄을 기준으로 그 위의 첫 의미 있는 줄을 봅니다(들여쓰기된 안내줄과 상태 표시줄은 건너뜀).

| 화면 | 상태 |
|---|---|
| `· Working… (1m 14s · ↓ 3.8k tokens)` 같은 스피너 줄, `esc to interrupt` | 작업 중 |
| 스피너 없는 `⏺` 응답 | 대기, 화면이 10분간 그대로면 완료 |
| 10분 이내의 `✻ Worked for 22s · done 2:34 PM` | 대기 |
| 같은 줄이 10분을 넘었거나 다른 날짜 | 완료 |
| `❯` 표시가 붙은 번호 선택지, `Do you want …` | 선택 필요 |
| 프롬프트가 없는 셸 터미널 | Orca 상태 |

시각은 영문·한국어 형식을 모두 해석합니다. 같은 화면에서 서브에이전트 패널(`⏺ main` 아래 `◯ 이름  설명  17s · ↓ 30.5k tokens`)과 상태 표시줄의 컨텍스트 비율도 읽습니다.
</details>

<details>
<summary>PM 팀</summary>

팀원에게 가는 모든 지시에는 팀 브리프 전체(목표, 범위, 결정 사항, 팀원별 산출물, 완료 조건, 금지 사항)가 동봉되어, 세션이 길어지거나 컨텍스트가 압축돼도 PM의 문맥이 유지됩니다. 팀원은 `REPORT_START … REPORT_END` 블록으로 보고하도록 요청받고, 팀원이 끝나면 위젯이 보고를 모아 PM에게 다음 단계를 묻습니다(기본은 승인 창, 자동 진행 가능, 라운드 상한 12). 팀 배치와 로그는 `~/.roca/teams.json`에 저장됩니다.
</details>

## 변경 보기와 리뷰 코멘트

세션 카드를 펼치고 **변경** 탭을 누르면 그 세션 작업 폴더의 git 변경을 봅니다.

- **작업 트리**(HEAD 기준, 커밋 안 한 변경) / **브랜치 전체**(`origin/HEAD`·`origin/main`·`origin/master`·`main`·`master` 중 처음 찾은 기본 브랜치와의 merge-base 기준) 를 고를 수 있습니다. 파일 목록(상태·경로·+/−, 추적 안 된 파일은 `U`)에서 파일을 누르면 헝크별 diff 가 열립니다. 파일 500개, 파일 하나당 300KB·2,000줄을 넘으면 앞부분만 보여 줍니다. 바이너리는 내용 없이 표시하고, diff 줄에 들어 있는 토큰·DB URI 같은 비밀 값은 마스킹합니다.
- 줄 번호를 누르면 그 줄에 코멘트(최대 500자)를 남깁니다. 쌓인 코멘트(최대 20건)는 **세션에 보내기** → 미리보기 확인 후 `[리뷰 코멘트 · N건] 1. 경로:줄 — 내용 … 위 코멘트를 반영하고, 끝나면 REPORT 블록으로 보고해 주세요.` 한 줄로 세션에 입력됩니다(줄바꿈은 공백으로 바뀝니다). 화면을 읽을 수 없거나, 권한·선택 프롬프트에 멈춰 있거나, 입력창에 쓰다 만 글이 있으면 보내지 않습니다(실행 중인 턴에는 보냅니다). 새로고침 뒤 목록에서 빠진 파일의 코멘트도 그대로 보내고, 보내지 못한 코멘트는 목록에 남깁니다.
- REPORT 가 도착한 세션 카드에는 **변경 보기** 배지가 한 번 뜹니다(누르면 변경 탭이 열립니다).
- 변경은 카드를 펼쳤을 때만 읽고(30초 캐시), 파일 diff 는 파일을 눌렀을 때만 읽습니다. 위젯은 경로를 직접 받지 않습니다: 세션 ID 로 메인 프로세스가 아는 작업 폴더(Orca `worktree ps`, 훅 이벤트의 cwd)만 열고, 파일은 직전 변경 목록에 있던 상대 경로만 허용하며(`..`·절대 경로 거부), 저장소 밖을 가리키는 심볼릭 링크는 읽지 않습니다. 홈 디렉터리 자체가 저장소 루트면 표시하지 않습니다. 실패한 세션은 60초(두 번째부터 5분) 쉬고, git 은 동시에 4개까지만 실행됩니다. 파일 이름은 패턴이 아닌 글자 그대로의 경로로 다룹니다(`GIT_LITERAL_PATHSPECS=1`). git 은 셸 없이, 외부 diff·textconv·fsmonitor 없이, 인덱스 잠금 없이(`GIT_OPTIONAL_LOCKS=0`) 실행됩니다.

## 세션 타임라인

세션 카드를 펼치고 **타임라인** 탭을 누르면 그 세션의 훅 이벤트(정확한 감지가 켜져 있어야 합니다)를 시간축으로 봅니다.

- 위쪽 요약: 턴 수 · 도구 호출/실패 수 · 서브에이전트 수 · 사용자 대기(응답 완료 → 다음 프롬프트) 합계 · 승인 대기(권한 요청 → 다음 도구 진행) 합계, 도구별 호출 수·시간, 가장 오래 걸린 호출 5개.
- 시간축 레인 3개: 메인 도구 호출(막대 길이 = 소요, 색 = 도구 종류, 실패는 빨간 테두리, 프롬프트는 세로선, 응답 완료는 점) / 서브에이전트 구간(겹치면 줄을 나눔, 그 안의 도구 호출 포함) / 대기(승인 대기 노랑, 사용자 대기 회색). 마우스를 올리면 시각·도구·요약·소요가 보이고, 누르면 아래 목록의 해당 줄로 이동합니다. **최근 10분 / 1시간 / 전체**로 확대합니다.
- 데이터는 `~/.roca/events.jsonl` 을 이미 읽어 들이는 증분 읽기에서 함께 쌓는 메모리 색인(세션당 최근 2,000건, 세션 100개)에서 만듭니다. LLM 호출이나 파일 전체 재읽기는 없습니다. 로그 회전(약 4,000줄 유지)으로 사라진 앞부분은 "이전 기록 없음"으로 표시합니다.
- 도구 입력·프롬프트 요약(120자)은 메인 프로세스에서 마스킹한 뒤 위젯으로 보내며, 팀 공유 데이터에는 들어가지 않습니다. 카드가 펼쳐져 있고 이 탭이 보일 때만 5초마다(그리기가 100ms를 넘으면 10초마다) 다시 읽습니다.

## 한도 소진 예측과 티켓별 비용

- **한도 예측**: 아래 한도 막대(Orca `account list` 의 `rateLimits.claude.session`·`weekly` 사용률·리셋 시각) 밑에 "이 속도면 약 1시간 40분 뒤 5시간 한도 소진 (리셋 14:30)" 또는 "리셋 전 도달 안 함"을 표시합니다. 최근 30분 샘플(1분에 한 번 이하, 사용률 숫자와 시각만)로 선형 회귀한 속도이며, 샘플이 적거나 들쭉날쭉하면 "(추정 불확실)"이 붙습니다. 샘플은 재시작 후에도 이어지도록 최근 30개만 `localStorage`(`roca-usage-samples`)에 둡니다. 폴링 주기는 바뀌지 않습니다.
- **한도 경고**: 사용률이 80%·95%(설정 → 감지와 알림 → 한도 경고 임계값)를 위로 넘을 때 토스트와 데스크톱 알림을 레벨별로 한 번 띄우고, 창이 리셋되면 다시 알립니다. 막대 색도 같은 값에서 노랑·빨강으로 바뀝니다.
- **티켓별 비용**: Jira에서 배치한 티켓마다 그 작업 폴더의 Claude Code 세션 파일(`~/.claude/projects/*.jsonl` 의 `cost-state`) 비용을 배치 시각 이후로 합쳐 카드·드로어에 "비용 $X.XX (세션 N)", 보드 위에 오늘 배치 비용 합계, 대시보드 아래에 티켓별 상위 3을 보여 줍니다.
- **주의**: 이 비용은 토큰 수 × 정가로 계산한 **추정치**입니다. Pro·Max·Team·Enterprise 구독 요금제에서는 실제 청구액이 아니며(사용량은 요금제 한도로 차감), API 청구도 Claude Console 사용량 페이지가 기준입니다. 기존 세션에 배치한 티켓은 그 세션의 배치 이전 비용도 포함됩니다. LLM 호출은 없습니다.

## 세션 노트 (recall)

`recall/` 은 끝난 에이전트 세션마다 짧은 엔지니어링 노트(`파일:줄` 근거가 있는 결론, 결정, 실패한 시도, 남은 의문)를 만들어 로컬 MongoDB에 저장하고, 이후 세션이 같은 분석을 반복하지 않게 합니다.

```bash
brew tap mongodb/brew && brew install mongodb-community && brew services start mongodb-community
cd recall && npm install
node cli.mjs install          # Claude Code / Gemini CLI / Codex CLI 에 SessionStart·SessionEnd·PreCompact·프롬프트 훅 + /recall 스킬 등록
node cli.mjs backfill --since 7d   # 선택: 지난 일주일 트랜스크립트 노트 생성
node cli.mjs search "iTerm 세션 매칭"
```

- **SessionEnd** 와 **PreCompact**(컨텍스트 압축은 대화의 자연스러운 장 경계이고, 며칠씩 열어 두는 세션을 잡을 유일한 시점) → 분리된 워커가 트랜스크립트를 요약 입력(프롬프트·응답만, 도구 출력 제외)으로 만들고 비밀 값을 마스킹한 뒤 `claude -p`(Haiku, JSON 스키마 강제)로 노트를 받아 `agentdesk.session_notes` 에 git 커밋·워크트리·관련 파일과 함께 저장합니다. 세션당 노트 하나이며 트리거마다 갱신됩니다.
- **모든 프롬프트**(세션의 첫 메시지 포함) → 프롬프트의 단어로 MongoDB를 검색해 가장 잘 맞는 노트 최대 3개를 컨텍스트로 덧붙입니다. 같은 워크트리 노트는 용어 1개, 같은 저장소의 다른 워크트리 노트는 2개 이상 일치해야 하므로 "세션"처럼 흔한 단어 하나로 무관한 작업이 끼어들지 않습니다. 노트가 의존한 파일이 그 뒤 바뀌었으면 `⚠ N file(s) changed since` 로 표시합니다.
- **SessionStart** → 프롬프트가 아직 없으니 브랜치 이름·수정 중인 파일·최근 커밋의 파일을 검색어로 삼아, 이 워크트리의 노트(또는 편집 중인 파일을 다룬 노트)만 최대 2개 보여 주고 없으면 아무것도 붙이지 않습니다.
- `/recall` 스킬과 `agentdesk-recall search | show | list [--worktree NAME | --all]` 로 직접 찾아볼 수 있고, MongoDB Compass(`mongodb://127.0.0.1:27017`, DB `agentdesk`)로 노트를 훑어볼 수 있습니다. `AGENTDESK_MONGO_URL` 을 원격으로 바꾸지 않는 한 데이터는 이 컴퓨터를 떠나지 않습니다.

## 문제 해결

- **세션 목록이 비어 있음** — 위젯은 `orca`를 `/usr/local/bin`, `/opt/homebrew/bin`, `/Applications/Orca.app/Contents/Resources/bin`에서 찾습니다. 호출이 실패하면 빨간 배너가 원인을 알려 줍니다. Orca 앱이 실행 중인지, 터미널에서 `orca --version`이 되는지 확인하고, 필요하면 `sudo ln -s /Applications/Orca.app/Contents/Resources/bin/orca /usr/local/bin/orca`를 실행하세요.
- **Orca 1.4 미만** — 화면 판독과 채팅에 `terminal read --screen`과 `--json`이 필요합니다. 배너가 업데이트를 안내합니다.
- **"터미널 보기"나 메시지 전송이 동작하지 않음** — macOS가 AgentDesk의 iTerm2 / Terminal 제어(자동화 권한)를 한 번 묻습니다. **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 허용하세요. 허용하지 않아도 상태는 읽지만 터미널 탭 전환과 입력은 되지 않습니다.
- **상태가 이상해 보임** — 정확 감지를 켜세요. 화면 판독은 Claude Code TUI 문구에 의존하지만 훅은 그렇지 않습니다.
